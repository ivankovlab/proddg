# ProDDG - database of ∆∆G datasets and predictors

To see the description of the DB and learn about ProDDG, check [main branch](https://github.com/ivankovlab/proddg)

## Purpose of this branch
This branch contains simple server wrapper around the RemoveOverlap function. It facilitates usage when the data is mostly stored in the databases, so the code was partially updated to work as an HTTP-server. To learn more, see [examples](./overlaps/README.md)
